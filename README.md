# Smart Expense Tracker

Smart Expense Tracker is a responsive and interactive web application developed using HTML, CSS, and JavaScript. It helps users manage their daily income and expenses in a simple and organized way.

## Project Objective

The objective of this project is to create a user-friendly expense management website that allows users to record, view, edit, delete, search, and filter their transactions while automatically calculating their financial summary.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Main Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Search transactions
- Filter transactions by category
- Automatic calculation of total income
- Automatic calculation of total expenses
- Balance calculation
- Form validation
- Dynamic transaction display
- Responsive design for desktop, tablet, and mobile
- Local storage for saving transaction data
